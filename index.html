How monthly coupons work
Create one coupon per month below. It is automatically applied on the student portal — only students within the 15-day renewal window will see the discounted price. All other students see the full price. Students never enter a code.
🏷️ Option 1 — Coupon code
Same code created on the portal. Students see name + discount.
Limits total discount for % type. E.g. 20% of ₹10,000 capped at ₹1,500.
This is what the student sees on the renewal screen. If blank, coupon code is shown.
💸 Option 2 — Flat discount
Give a fixed rupee or % off without a coupon code.
ℹ️
Use this when you want to run an offer directly — no coupon code on the portal needed. Students in the renewal window see this discount automatically.
