Deployment steps
One-time per client — takes about 3 minutes
  1. Open the client's blank Google Sheet → Extensions → Apps Script
  2. Delete everything in Code.gs → paste the generated code above → Save (Ctrl+S)
  3. Click + next to Files → HTML → name it exactly Index → paste Index.html from GitHub → Save
  4. Click + → HTML → name it exactly Student_Demo → paste Student_Demo.html from GitHub → Save
  5. In the function dropdown select setupSheets → click Run → grant permissions when prompted.
    This creates all tabs, pulls initial Classplus data, and registers the hourly sync trigger automatically.
  6. Deploy → New deployment → Web App
    Execute as: Me  |  Who has access: Anyone → click Deploy → copy the Web App URL
