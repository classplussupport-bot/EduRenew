CLIENT ONBOARDING
Register a New Client
Follow these steps for every new client
1
Create a blank Google Sheet for the client → copy the Sheet ID from the URL (long string between /d/ and /edit)
2
Open Register Client tab → fill all 7 fields → click Generate Code.gs → click Copy all
3
Open the client's Google Sheet → Extensions → Apps Script → select all existing code → delete → paste the copied Code.gs → Ctrl+S
4
In Apps Script → click Project Settings (⚙️ gear icon) → tick "Show appsscript.json manifest file" → click appsscript.json → paste the appsscript.json from below → Ctrl+S
5
Deploy → New deployment → click gear ⚙️ → Web App → Execute as: Me → Who has access: Anyone → Deploy → copy the Web App URL
⚠️ For all future updates: Manage deployments → pencil ✏️ → New version → Deploy. Never create a new deployment.
6
In Apps Script editor → select setupSheets from the function dropdown → click Run → grant permissions when prompted
This creates all required tabs and starts hourly auto-sync from Classplus.
7
Share with client:
📊 Tutor Dashboard: /exec
🎓 Student Portal: /exec?page=student
